# 2D World Pathfinding

Algorithmes de pathfinding dans un monde 2D.

## Algorithmes

- BFS

## Version de Node JS

La version de Node JS utilisé pour réaliser le projet est : **24.14.0**

## Mise en oeuvre

Pour lancer le projet il faut avant tout installer les libs :

```bash
npm install
```

Pour démarrer le projet :

```bash
npm run dev
```

Si besoin de build pour le déployer :

```bash
npm run build
```
